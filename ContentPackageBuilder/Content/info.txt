Protagonist Never Die (C#)

Uses C# scripts and requires "Lua For Barotrauma" as a dependency.
The code was generated with AI assistance and debugged by me. Please do not use this mod if that bothers you.

Original Mod "Protagonist's Halo(Special Headset)"
https://steamcommunity.com/sharedfiles/filedetails/?id=3567916643

Here is C# version (utilizing a C# script to resolve some peculiar issues with XML).
The intended effect remains essentially the same: preventing bots or player characters from suddenly dropping dead.

However, the crafting recipe has been modified here, and the functionality has been broken down: in addition to the headset itself, you also need to insert four specific functional chips into it.

1. Immortality Chip: Provides the same effects as "Miracle in Progress" and "Pressure Resistance"; when a character's health reaches -100, they will be ignored by monster AI.
2. Resuscitation Chip: Rapidly restores health when it drops below a certain threshold (has a cooldown and consumes durability).
3. Teleportation Chip: Teleports the character to the main submarine's spawn point when their health drops below a certain threshold (has a cooldown and consumes durability).
4. Health Scan Chip: Provides the same effect as a Health Scanner HUD.

An update to ensure compatibility may follow the DLC release (it is rumored that the developers will add support for C# scripting, and adjustments will be made at that time).
