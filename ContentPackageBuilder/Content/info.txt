Protagonist Never Die (C#)

Developed with AI assistance; editing, review and debugging are handled by me. Please do not use this mod if that bothers you.
The code and content have been reorganized around the official plugin system (IBarotraumaPlugin). It no longer depends on Lua For Barotrauma; the compiled ".dll" is loaded directly by the game's native plugin loader.

Please note: using .dll files in a mod carries risks, and the game warns about this in its own UI.
To review the code externally, visit GitHub: https://github.com/chunhaqiushif/ProtagonistNeverDie
To review it in-game, expand the mod at the prompt and click the decompile option to view the code.

This mod adds a special self-injecting headset. Various chips can be inserted into it for different effects:
1. Immortality Chip: Grants the same effects as "Miracle in Progress" and "Pressure Resistance"; at -100 vitality the character is ignored by monster AI.
2. Resuscitation Chip: Rapidly heals the wearer once vitality drops below a certain threshold (has a cooldown and consumes durability).
3. Teleportation Chip: Teleports the wearer to a spawn point of the main submarine once vitality drops below a certain threshold (has a cooldown and consumes durability).
4. More...

BA halo style patch: https://steamcommunity.com/sharedfiles/filedetails/?id=3845185576

Original XML mod "Protagonist's Halo (Special Self-Injecting Headset)"
https://steamcommunity.com/sharedfiles/filedetails/?id=3567916643

This is its definitive version (using C# scripts to work around some odd XML issues).
The intended effect is essentially the same: preventing bots or player characters from suddenly dropping dead.
However, the crafting recipe has been changed here and the functionality split up: besides the headset itself, you also need to insert four functional chips into it.

(Note: this mod is not compatible with the original XML mod.)
